# The One-Line Exit

A one-line resignation letter, written to be funny: a formal resignation that ends in a confession.

> I hereby resign as head lifeguard, effective immediately, after eight years of never learning to swim.

## Run it

`python3 main.py` writes the entry to `/output/entry.txt` (creating `/output` if needed). The output is deterministic: every run writes the same single line, with no trailing newline.
